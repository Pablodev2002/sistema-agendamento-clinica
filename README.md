# Sistema de Agendamento para Clínica de Saúde Mental

## Sobre o projeto

Projeto acadêmico extensionista realizado em equipe no curso de Análise e Desenvolvimento de Sistemas, na disciplina de Programação para Dispositivos Móveis em Android.

A proposta descrita no relatório é uma solução integrada composta por uma plataforma web e um aplicativo móvel para apoiar o cadastro e o gerenciamento de pacientes e o agendamento de consultas em uma clínica de saúde mental.

## Funcionalidades descritas no relatório

- Cadastro e gerenciamento de pacientes.
- Cadastro de estagiários.
- Criação e consulta de agendamentos.
- Organização de horários e atendimentos.
- Banco de dados para organizar informações do sistema.

## Tecnologias mencionadas

- Python
- JavaScript
- React Native
- MySQL
- Visual Studio Code
